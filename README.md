# Фото на документ

[![Release](https://img.shields.io/github/v/release/Antonix84/fotodoc-size?display_name=tag&label=release)](https://github.com/Antonix84/fotodoc-size/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078D4)](#системные-требования)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

Подготовка фотографий на документы прямо из Adobe Photoshop: программа находит
лицо, выравнивает наклон, масштабирует по ширине лица и ставит голову на
направляющие шаблона. Работает по горячей клавише: выбрали размер — готовый файл
лежит рядом с исходником.

Программа не заменяет ретушь и цветокоррекцию — их вы делаете в Camera Raw или
Photoshop как обычно. Она берёт уже подготовленный снимок и доводит геометрию до
норм: 3,7 × 4,7, 3,0 × 4,0, 3,5 × 4,5 и 3,7 × 3,7 см, 762 ppi (30 пикселей на
миллиметр).

## Возможности

- **Лицо по 106 точкам** — SCRFD + 2d106det (InsightFace), без Python на машине
  пользователя: всё внутри exe.
- **Наклон по овалу лица.** Угол считается как взвешенная медиана шести линий;
  овал весит больше остальных, потому что рот и брови у живых людей кривые чаще
  всего.
- **Масштаб по ширине лица** — 18,5 мм по скулам для основного размера, а не по
  причёске.
- **Голова ставится по волосам:** 3,1 мм от верхнего края кадра до верхушки.
  Подбородок ограничен 11…15,7 мм, чтобы пышная или короткая причёска не увела
  голову к краю.
- **Поправка на круглое лицо** — определяется автоматически по трём отношениям
  или задаётся вручную.
- **Свои размеры** — в окне выбора или секцией в `passport.ini`.
- **Проверка готового файла** тем же распознаванием и окно с отчётом: ширина
  лица, подбородок, запас над волосами, наклон, предупреждения о выходе за нормы.
- **Без консольного окна** — Photoshop запускает программу скрыто, журнал пишет
  сама программа.

## Системные требования

- Windows 10 или 11, 64-бит.
- Adobe Photoshop с поддержкой сценариев `.jsx` (проверено на Photoshop 26.x).
  Photoshop в поставку не входит и требует собственной лицензии.
- Около 160 МБ на диске для распакованной сборки.
- Python нужен только для сборки из исходников (3.10+).

## Скачать и установить

1. Скачайте `fotodoc-size-2.0.0-win64.zip` со страницы
   [Releases](https://github.com/Antonix84/fotodoc-size/releases/latest).
2. Распакуйте архив в постоянную папку, например `C:\Tools\fotodoc-size`.
   Переносить папку после установки нельзя: путь к программе прописывается в
   скрипт Photoshop.
3. Запустите **`install.cmd`** (или в командной строке:
   `passport.exe install`). Программа найдёт Photoshop, положит скрипт
   `passport-photo2.jsx` в `Presets\Scripts` и покажет окно с результатом.
   Если Photoshop установлен в нестандартное место, путь можно вписать в
   `passport.ini`, секция `[photoshop]`.
4. В Photoshop назначьте горячую клавишу:
   **Действия** (Alt+F9) → новое действие → меню панели → **Вставить пункт
   меню** → **Файл → Сценарии → passport-photo2.jsx** → «Остановить запись»,
   затем задайте действию клавишу.

Windows SmartScreen может предупредить о неизвестном издателе — у exe нет
цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

Python на компьютере не нужен: интерпретатор, модели, шаблон и скрипт лежат
внутри сборки.

## Как пользоваться

1. Откройте снимок в Photoshop, при необходимости обработайте в Camera Raw.
2. Нажмите назначенную клавишу.
3. В окне выбора укажите размер. Можно не водить мышью: цифра на нумпаде или в
   верхнем ряду выбирает размер по номеру, `Enter` — подтвердить, `Esc` — отмена.
4. Дождитесь отчёта. Готовый файл сохраняется рядом с исходником с суффиксом
   `_3,7x4,7см` (меняется в `passport.ini`).

Окно выбора и отчёт всегда поверх Photoshop. Отчёт закрывается сам через
`report_timeout_sec` секунд (по умолчанию 90, `0` — не закрывать).

## Размеры

| Пресет | Кадр | Пиксели | Ширина лица |
|---|---|---|---|
| `37x47` | 3,7 × 4,7 см | 1110 × 1410 | 18,5 мм |
| `30x40` | 3,0 × 4,0 см | 900 × 1200 | 15,0 мм |
| `35x45` | 3,5 × 4,5 см | 1050 × 1350 | 17,5 мм |
| `37x37` | 3,7 × 3,7 см | 1110 × 1110 | 18,5 мм |

Высота кадра и положение головы пересчитываются пропорционально: у 3 × 4 см
запас над волосами получается 2,64 мм. Для 3,7 × 4,7 используется шаблон
`3,7x4,7.psd`; остальные размеры строятся по тем же долям кадра.

Свой размер добавляется в окне выбора галочкой **Свой размер** или секцией
`[sizes.ID]` в `passport.ini`. Подробности — в
[документации](docs/how-it-works.md#passportini).

## Команды

```
passport.exe            работать с заданием от Photoshop
passport.exe 30x40      сразу в этом размере, без окна выбора
passport.exe install    поставить скрипт в Photoshop, показать результат
passport.exe settings   открыть passport.ini в блокноте
passport.exe --log Ф    писать весь вывод в файл Ф (так вызывает Photoshop)
```

## Настройка

Все настройки — в `passport.ini` рядом с программой. Файл создаётся при первом
запуске, содержит русские комментарии и читается «Блокнотом» (UTF-8 с BOM).
Пересобирать exe после правок не нужно.

| Секция | Что в ней |
|---|---|
| `[general]` | формат и качество сохранения, суффикс и папка результата, ppi, порог распознавания |
| `[paths]` | папки работы, моделей и шаблонов (пусто — рядом с программой) |
| `[photoshop]` | путь к `Photoshop.exe` и размер без вопросов `auto_size` |
| `[geometry]` | положение головы: запас над волосами, границы подбородка, ширина и центр лица |
| `[mvd]` | нормы ГОСТ Р 5103 — для отчёта |
| `[tilt]` | веса линий при выравнивании наклона |
| `[round_face]` | пороги и величины поправки на круглое лицо |
| `[sizes]` / `[sizes.ID]` | порядок размеров и сам размер: подпись, миллиметры, шаблон |

Запись в ini бережная: меняются только строки `ключ = значение`, комментарии и
порядок секций остаются как были. Если файл повреждён, программа не переписывает
его, показывает ошибку и работает по встроенным значениям.

## Сборка из исходников

Нужен Python 3.10+ и Windows.

```bat
python -m pip install -r requirements-dev.txt
python tools\build_exe.py
```

Результат — папка `dist\passport`: `passport.exe` и `_internal` с моделями,
шаблоном и скриптом. `passport.ini` создаётся при первом запуске (в релизном
архиве лежит готовый файл с комментариями). Для запуска из исходников:

```bat
python passport.py install
python passport.py settings
```

Установщик из исходников пропишет в скрипт Photoshop `pythonw.exe`, чтобы не
появлялось консольное окно.

Сборка релизного архива:

```bat
python tools\package_release.py 2.0.0
```

## Структура

```
passport.py             окно выбора, отчёт, проверка результата, install/settings
passport-photo.jsx      скрипт Photoshop: выгрузка копии, запуск, сборка результата
passport.ini            настройки по умолчанию с комментариями
pp/config.py            чтение и запись ini, размеры, папки
pp/face.py              распознавание лица и 106 точек
pp/geometry.py          наклон, масштаб, положение головы, круглая голова
pp/bridge.py            обмен файлами с Photoshop
pp/installer.py         поиск Photoshop и установка скрипта
models/                 det_10g.onnx, 2d106det.onnx (InsightFace)
tools/                  сборка, установка, проверки, упаковка релиза
docs/                   как устроена геометрия и откуда взялись числа
```
